SPACE PLATFORMER - UNITY IMPORT

These PNG files are cropped from the generated concept sheet.

Recommended Unity settings:
1. Drag the PNG files into Assets/Sprites.
2. Select an image in the Project window.
3. Texture Type: Sprite (2D and UI)
4. Sprite Mode:
   - Single for these cropped category sheets.
   - Multiple if you use Unity Sprite Editor to slice individual sprites.
5. Filter Mode: Point (no filter)
6. Compression: None
7. Apply.

IMPORTANT:
The source artwork was generated as one presentation/concept sheet, so the dark panel
background is baked into the image. For production-ready individual sprites, the best
next step is to generate/rebuild dedicated sprite sheets with transparent backgrounds,
consistent cell sizes, and animation frames.
